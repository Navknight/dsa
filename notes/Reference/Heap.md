# Heap

Top-k, running median, always-take-the-min. O(log n) push/pop.

Related: [[priority_queue]] [[Heap Sort]]

## Problems

```base
filters:
  and:
    - file.inFolder("notes/Problems")
    - file.hasLink(this.file)
views:
  - type: table
    name: Problems
    order:
      - file.name
      - insight
      - time
      - difficulty
      - star
      - mastery
```
